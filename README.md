# Telegram Bot - Подготовка к экзаменам по русскому языку и литературе

Telegram-бот для помощи в подготовке к экзаменам по русскому языку и литературе.

## Возможности
- Объяснение тем по русскому языку (орфография, пунктуация, морфология, синтаксис и др.)
- Анализ литературных произведений и персонажей
- Тренировочные задания и тесты
- Помощь в написании эссе и сочинений
- Персональный план подготовки

## Установка и запуск
1. Установите зависимости:
```bash
pip install -r requirements.txt
```

2. Запустите бота:
```bash
python bot.py
```
